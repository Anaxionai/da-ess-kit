# Try it: free sites where you practise in the browser

Learn cards ask you to **try** each new idea for 15 to 20 minutes. These free sites let you do that, most with nothing to install.
A site that needs an account says so in its row. Every address was checked on 24 November 2026.

## Spreadsheets

| Site | Address | Use it for |
|---|---|---|
| Excel's own tutorials | In Excel: **File > New**, then search for `tutorial` | Microsoft's practice workbooks, such as "Get started with Formulas" and "Make your first PivotTable". Each sheet tells you what to type and checks your answer. |
| Excel for the web | https://excel.cloud.microsoft/ | Free Excel in the browser with a Microsoft account. It has `XLOOKUP` and `TEXTSPLIT`, so you can try them even if your laptop's Excel is older. |
| Microsoft Excel help and training | https://support.microsoft.com/excel | The official page for every function, with short videos. Search for the function's name. |
| Exceljet | https://exceljet.net/ | Short, clear examples of each function and formula pattern. |
| The kit's month of sales | [`data/sheets/month-sales.xlsx`](data/sheets/month-sales.xlsx) | Real invoice lines to practise sort, filter, formulas and PivotTables on. |

## SQL

| Site | Address | Use it for |
|---|---|---|
| DuckDB web shell | https://shell.duckdb.org/ | Run SQL in the browser, over a CSV file from your laptop. The Launchpad uses it with [`data/ipl/season.csv`](data/ipl/README.md). Your file never leaves your computer. |
| SQLBolt | https://sqlbolt.com/ | Short interactive lessons on SELECT, WHERE, joins and grouping. |
| SQLZoo | https://sqlzoo.net/ | Graded SQL questions on small tables, from SELECT to joins. |
| Window Functions | https://www.windowfunctions.com/ | Practice questions on window functions only (P2, week 5). |
| DataLemur | https://datalemur.com/ | SQL interview questions from real companies. Many need a free account. For week 9's timed tests. |

## Python and pandas

| Site | Address | Use it for |
|---|---|---|
| Python Tutor | https://pythontutor.com/visualize.html | Run Python one line at a time and watch variables, lists and dictionaries change. |
| futurecoder | https://futurecoder.io/ | A free Python course for complete beginners, with exercises and hints. |
| 10 minutes to pandas | https://pandas.pydata.org/docs/user_guide/10min.html | The official short tour of pandas. Copy each example into a `# %%` cell and run it. |
| Kaggle Learn: pandas | https://www.kaggle.com/learn/pandas | Short pandas lessons with exercises in the browser. Needs a free Kaggle account. |
